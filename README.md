# NATO vs BRICS

Статичний сайт-довідник з порівнянням НАТО та БРІКС: загальні показники, 42 країни (32 НАТО + 10 БРІКС) і 175 моделей озброєння з короткими ТТХ (бронетехніка, авіація, ППО та ракети, флот).

Без збірки й залежностей: чистий HTML/CSS/JS.

## Можливості

- **Огляд**, **Порівняння сил** (сума по блоках, перемикачі «без США» / «без Росії»), **Країни**, **Моделі озброєння**, **Методологія**.
- **Дуель**: пряме порівняння будь-яких двох країн (напр. Польща–Китай, США–Індія) за 13 показниками та похідними (витрати на людину, % ВВП).
- Двомовність: українська та англійська (кнопка UA/EN у шапці, також `?lang=en`). Переклади даних лежать у `js/data/en/`; англійські списки моделей мають збігатися з українськими за порядком.
- Глибокі посилання: `#countries/PL/CN`, `#duel/US/IN`, `#weapons/air/f-35a-b-c-lightning-ii`.

## Запуск локально

```bash
python -m http.server 8000
```

Відкрийте http://localhost:8000. Файл `index.html` можна відкрити й напряму, але через сервер надійніше.

## Структура

- `index.html` — каркас і підключення скриптів
- `css/style.css` — стилі (темна/світла тема за налаштуванням системи)
- `js/data/` — дані: `countries-*.js`, `weapons-*.js`, `blocs.js`, `core.js`
- `js/view-*.js` — вкладки сайту (у т.ч. `view-duel.js`), `js/main.js` — hash-роутер з глибокими посиланнями

## Як додати дані

- Країна: додайте рядок у `js/data/countries-nato.js` або `countries-brics.js` (порядок полів описано в `js/data/core.js`).
- Модель озброєння: додайте кортеж у відповідний `js/data/weapons-*.js`.

## Публікація на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

## Застереження

Звірено з першоджерелами (21.09.2026): оборонні бюджети за 2025 рік (SIPRI, звіт НАТО) і ядерні арсенали (FAS, початок 2026). Решта показників (чисельність армій, техніка, населення, ВВП) і ТТХ моделей — наближені оцінки без звірки; в інтерфейсі вони позначені «≈». Джерела розходяться, тому це довідник, а не офіційне джерело. БРІКС — не військовий союз: суми по ньому є арифметикою країн-членів.
